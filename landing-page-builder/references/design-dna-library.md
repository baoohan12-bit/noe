# Design DNA Library

> Bộ "DNA thiết kế" proven cho landing page coaching/info-product market.
> Mỗi DNA là 1 combo (vibe + palette + font + layout) đã chứng minh hiệu quả ở thị trường VN.
>
> **Cách dùng:** Match niche/vibe user → pick 1 DNA → SKILL.md sẽ áp dụng palette từ `color-systems.md` + layout từ `layout-patterns.md` + snippet từ `code-snippets.md`.

## 9 DNA Profiles

### DNA-01 — Dark Glow Editorial
- **Vibe:** Modern minimal · dark glow · stadium energy
- **Niche fit:** Video editing coaching, freelance skill, mindset cao năng lượng
- **Palette ref:** `color-systems.md` #1 Dark Glow Red
- **Font pairing:** Plus Jakarta Sans (h) + Inter (b)
- **Layout pattern:** Pattern 1 (Vertical Long Centered)
- **Signature elements:**
  - Hero badge pill + headline 3-line bold
  - VSL video section custom với play button gradient
  - Sticky CTA bar top, ẩn khi scroll xuống
  - Ecosystem feature cards 3-col với hover lift
  - Timeline 4-step với connector line
  - FAQ accordion với chevron animation
- **Khi pick:** User là freelancer/coach skill kỹ thuật, audience nam giới + nữ trẻ, message cần "high-income/đổi đời"

## 🎨 Hybrid DNA — Combine 2 DNA

Khi user có visual brand đã có (logo, banner màu cụ thể) hoặc niche overlap 2 DNA, dùng hybrid:

**Quy tắc hybrid:**
- **Layout** lấy từ DNA-A (niche fit)
- **Palette** lấy từ DNA-B (visual match brand đã có)
- **Font** lấy từ DNA-A (giữ tone niche)

**Ví dụ thường gặp:**
- DNA-04 layout (warm editorial) + DNA-08 palette (luxury burgundy) = **Personal brand workshop phụ nữ premium** (case Vi Hoa)
- DNA-01 layout (dark editorial) + DNA-06 palette (red on white) = **Skill coaching năng lượng cao trên light bg**
- DNA-05 layout (founder photo) + DNA-09 palette (cosmic) = **Spiritual coach personal brand**

## 📋 Output format khi Claude đề xuất DNA cho user

Khi đến Bước 2 trong `SKILL.md`, Claude phải show output dạng:

```
Mình đề xuất 3 DNA phù hợp với [niche của user]:

**1. DNA-XX — [Tên]** ⭐ Recommend
   Vibe: [vibe]
   Lý do hợp với bạn: [1 câu cụ thể]

**2. DNA-YY — [Tên]**
   Vibe: [vibe]
   Lý do: [1 câu]

**3. DNA-ZZ — [Tên]**
   Vibe: [vibe]
   Lý do: [1 câu]

Mình recommend #1 vì [lý do cụ thể nhất gắn với context user].
Bạn chốt 1, hay muốn hybrid 2 DNA?
```

**Quy tắc pick DNA cho user:**
- Niche match → 1 DNA primary
- Nếu user có visual brand sẵn (logo/banner màu) → đề xuất hybrid với DNA palette match
- Nếu user mơ hồ → đề xuất DNA default theo Quick Pick table + 2 alternative
- **KHÔNG bao giờ** đề xuất tự sáng tạo DNA mới — luôn pick từ 9 DNA + hybrid combo
